# Quy tắc dự án Học cùng Cherry

Luôn đọc và làm theo `AGENTS.md` ở thư mục gốc repo (quy tắc chung cho Claude và Gemini) và `GEMINI.md`.
Khi tiếp quản việc dở của Claude: đọc `docs/gemini-tiep-quan.md` và file tiến độ `docs/tien-do/<nhánh>.md`.
Không đẩy thẳng lên `main`; làm trên nhánh `gemini/<việc>` hoặc đúng nhánh được giao, mở pull request để thầy Linh duyệt.
Hỏi thầy trước khi chạy lệnh xóa file hoặc `git push --force`.
