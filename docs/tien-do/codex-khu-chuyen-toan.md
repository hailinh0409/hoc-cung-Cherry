# Khu Chuyên Toán

- Trạng thái xong, chờ thầy duyệt.
- Thêm khu cạnh các khối 6–12. Chỉ nhận đề tự luận LaTeX, thầy duyệt trước khi học sinh thấy.
- Bật quyền Chuyên Toán theo tài khoản từ màn quản lý học sinh. Quyền dùng cột môn hiện có. Đề dùng mã khu vực ở cột chương để tương thích kiểu dữ liệu của khối.
- Kiểm tra bản ghép, đề hợp lệ, đề rỗng, đề trắc nghiệm, cấp và thu hồi quyền bằng dữ liệu giả.
- Các file liên quan nằm trong `client/`, `app/api/` và `lib/topics.js`.
